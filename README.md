A pixel-perfect frontend clone of PayPal's enterprise landing page, featuring fully styled user authentication flows (Login & Signup pages) and dynamic navigation dropdowns.

---

## 🚀 Key Features

* **Interactive Mega-Menus**: Desktop-grade dropdown navigation menus showing services, features, and resources using clean Vanilla JS.
* **Full Authentication Interfaces**: Dedicated, pixel-perfect styled Login and Signup pages matching the modern PayPal brand identity.
* **Responsive Flexbox Grid**: Built using modular CSS structure, wrapping complex content blocks and features tables seamlessly across all viewport dimensions.
* **Micro-Animations**: Hover states, interactive inputs, and button transitions providing an authentic, native platform feel.

---

## 🛠️ Technology Stack

* **Structure**: HTML5 (Semantic structures)
* **Styling**: CSS3 (Flexbox, CSS variables, Custom Transitions)
* **Logic**: Vanilla JavaScript ES6 (Dropdown menus toggle logic)

---

## 📂 Project Structure

```text
├── index.html          # PayPal main landing page
├── login.html          # Styled Login gateway
├── signup.html         # Styled Signup gateway
├── css/
│   └── style.css       # Core layout styles & responsive queries
├── js/
│   └── script.js       # Toggle mega-menus controllers
└── images/             # Brand logos & icons
```

---

## ⚡ Setup & Run

To run this project locally, simply clone the repository and open the `index.html` file in any modern web browser:

1. Clone the repository:
   ```bash
   git clone https://github.com/Sayed-Herzallah/paypal-full-landing-clone.git
   ```
2. Navigate to the project directory:
   ```bash
   cd paypal-full-landing-clone
   ```
3. Open `index.html` in your browser.
